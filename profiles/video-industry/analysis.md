# 评估目标

评估一条信息是否值得中文视频博主在未来 24–72 小时内制作内容，重点判断其时效性、行业影响、观众价值和可展示性。

# 评分标准

- **9–10：必须跟进。** 主流视频平台规则、分发或变现发生重大变化；重要创作工具或设备带来明显工作流变化；有可靠证据且影响广泛。
- **7–8：值得制作。** 有明确新事实、可操作价值或可展示素材，能形成具体的行业解读或实测选题。
- **5–6：进入素材库。** 有一定价值，但影响有限、信息不完整，或适合与其他新闻合并制作。
- **3–4：低优先级。** 常规更新、厂商宣传、缺乏实际影响或与目标观众关系较弱。
- **0–2：噪音。** 无来源传闻、标题党、夸大结论或无法验证的信息。

# 加分因素

- 有官方公告、价格表、更新日志、代码仓库、公开数据或可复现实测；
- 能明确回答“这会怎样改变视频博主的选题、制作、分发或收入”；
- 具备可录屏、可截图、可对比或可实拍的视觉材料；
- 同时影响多个平台或代表明显行业趋势；
- 存在值得解释的限制、争议或真实用户反馈。

# 评估要求

区分正式发布、测试功能、地区灰度、厂商主张、媒体判断和社区猜测。不要把单个账号的流量变化解释为平台算法结论。输出 3–5 个具体主题标签。
